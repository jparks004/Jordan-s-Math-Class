# Coach Jordan’s Math & Soccer Hub

A beginner-friendly static website for **Jeff Davis High School** designed to be published directly with **GitHub Pages**.

## Files in this project
- `index.html`
- `style.css`
- `script.js`

## Publish on GitHub Pages (simple steps)
1. Push this repository to GitHub.
2. In GitHub, open your repository and go to **Settings**.
3. Click **Pages** in the left sidebar.
4. Under **Build and deployment**:
   - **Source**: select **Deploy from a branch**
   - **Branch**: choose your default branch (usually `main`) and folder `/ (root)`
5. Click **Save**.
6. Wait about 1–2 minutes, then refresh the Pages settings. Your site URL will appear at the top.

## Local preview (optional)
Open `index.html` directly in a browser, or run a simple server:

```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
